  1.  DATASET SUMMARY
=====================================================================

  Source database : NCBI
  Task            : Binary classification (PMT vs. non-PMT)
  Redundancy tool : CD-HIT (40% sequence identity threshold)

  +----------------------------------------------------+----------+
  | Stage                                              | Count    |
  +----------------------------------------------------+----------+
  | Raw NCBI download (positive / methyltransferase)  | 41,146   |
  | After quality filtering (positive)                | 17,280   |
  | Raw NCBI download (negative / non-PMT)            | 33,061   |
  | After CD-HIT -- positive sequences                |  2,862   |
  | After CD-HIT -- negative sequences                |  3,009   |
  | Final balanced dataset (2,862 + 2,862)            |  5,724   |
  | Training set  (80%)  -- 2,290 PMT + 2,290 non-PMT|  4,580   |
  | Test set      (20%)  --   572 PMT +   572 non-PMT |  1,144   |
  +----------------------------------------------------+----------+

  Exclusion criteria:
    - Sequences shorter than 50 amino acids
    - Entries annotated as hypothetical / partial /
      putative / predicted
    - Ambiguous amino acid characters (B, J, O, U, X, Z)
